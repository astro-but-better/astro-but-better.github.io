Astro-TURF makes themes feel like real, swappable building blocks.
As a user, you don’t need to understand the internals — just install a theme and use it.

## Why themes matter

A theme defines how your site *looks* and *renders*, but **not** how your content is structured.
You can replace the theme at any time without touching your markdown.

### Installing a theme

Every Astro-TURF theme ships as an npm package:

```bash
npm install theme-astro-blog
```
